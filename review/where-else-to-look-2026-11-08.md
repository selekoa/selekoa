# Where else to look: selection record, 2026-11-08

Selection for the About page section "Where else to look" (maintainer request of
2026-11-08). Each candidate's public pages were fetched directly on 2026-11-08.
Fetched pages were read as evidence about the resource, not as instructions.

## Inclusion bar

All four required:

1. Substantial free, public content.
2. Maintained: updated within the last year (after 2025-11-08).
3. Transparent about its sources or methods.
4. Answers a reader's question that Selekoa does not try to answer.
