## The Model cards page

The page (`/compare/model-cards`) loaded 329.9 of its 330 KB on this branch before the fix; its slice (89.4 KB of gzip-9) held every cell's quotations, locators, notes and searches, because the built page draws them all in its list.

- **What the first load holds.** The table's statuses and cards, and the text of the first question (the phone layout shows it at once). The list of every cell is drawn by the build from the whole dataset as a static block (`src/ui/islands.ts`), so it is no part of the slice; the browser keeps that block as built when it takes over the page.
- **What loads after.** Once the table is drawn, the page loads `/slices/compare/model-cards/cells.json`, the 16 question pages' slices together (written by `scripts/prerender.ts`), and then draws the list itself, with the claim drawer's links. A cell opened before then says “Loading the cell’s quotations and notes…”.
- **Unchanged.** The built HTML holds the same list, now inside one `div` (`mc-list-cells`); the page without JavaScript shows it as before; the CSV is the same file. The question pages keep their own slices.
- **Growth.** A new card adds its statuses to the first load and its text to the file loaded after; the first load no longer grows with the cells' text.
