# Repository record audit, 15 October 2026

The public repository will start with fresh history, so the editorial policy now requires corrections, admissions and dispositions to be recorded in tracked files, not only in commit messages (maintainer decision of 2026-10-15; [policy review, section 8](../docs/policy-review-2026-10-15.md#8-publication-route-fresh-history-public-repository)). This note records a check of that requirement against `main` at `29c8c38`. It is a read-only machine audit: a script compared records by ID for each commit that changed `data/`, and the files changed with each commit were searched for a matching tracked record. No data record was changed.

## Coverage

Nineteen commits on `main` change `data/`: the genesis, 13 admissions, 4 corrections and 1 mechanical change (the `sortName` field, documented in [ontology](../docs/ontology.md)). Seventeen have a prose record in `review/`, `research/` or `docs/`. The other two have their reason only in the `description` field of a JSON before-snapshot; this note now gives that reason in prose (below).
