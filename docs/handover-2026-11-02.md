## Rules that matter most on a smaller plan

- One data branch at a time; merge it before starting the next, so releases never clash.
- A session that runs while main moves must merge `origin/main` before its final checks (no rebase), and rerun `pnpm docs:coverage`.
- Codex does anything that needs web.archive.org or another host cloud sessions cannot reach, and every cross-family check. Claude sessions apply the results from the Codex reports.
- Merge only at a reviewed commit, then check that the branch has no commits left unmerged (`git rev-list --count origin/main..origin/<branch>` is 0).
- Never raise a bundle budget to make room; find it in the change. Search and the start page are near their limits.
