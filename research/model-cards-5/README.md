# Model cards compared, pack 5

Candidate research outside application data, prepared by **Claude** on 2026-11-06 and 2026-11-07, together with [pack 4](../model-cards-4/). Nothing here is human-reviewed or admitted. The review note covering both packs is [`review/model-cards-packs-4-5-2026-11-07.md`](../../review/model-cards-packs-4-5-2026-11-07.md).

## Limits

- The Gemini 2.5 Flash copy read prints “published/updated December, 2025”; the population's earliest located expression (archive capture of 2025-08-30) was not read, because web.archive.org refused the preparer.
- The Claude Opus 4.6 PDF's default text layer interleaves drop capitals; affected quotations are matched in pdftotext's raw reading order and marked so.
- Claude Sonnet 4.5's source is the same file as the dataset's `source-ab-claude-sonnet45-card` (same SHA-256); its existing quotations count toward the same quotation budget.
